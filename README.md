# WorkSphere

A full-stack project management application built using the MEAN stack.

## Technology Stack

- **Frontend:** Angular
- **Backend:** Node.js and Express.js
- **Database:** MongoDB

## Planned Features

- User authentication and role-based access
- Project and task management
- Team member assignments
- Project analytics dashboard
- Activity tracking
- Automated testing

## Project Status

🚧 Currently in development.
